# ESG Portfolio Decarbonization Engine

An interactive serverless dashboard and Python API calculating Weighted Average Carbon Intensity (WACI) and Net Zero 2030 transition pathways for equity portfolios under GHG Protocol standards.

## Features
* **WACI Calculation Engine:** Computes portfolio carbon intensity ($tCO_2e / \$M$ Revenue) across Scope 1 & 2 emissions.
* **Interactive Frontend Dashboard:** Visualizes company contributions, intensity charts, and corporate logos dynamically.
* **Serverless Backend:** Built with Python zero-dependency runtime for instant Vercel deployment.
